Mitigations

  • Blur → OCR + human review
  • Small chunks → 50 overlap, 450-550 size
  • Top-K → 3-4 + “No answer” fallback
  • Update → re-chunk + re-embed only that file (Basic cheapest)

For Builders — cost

Embedding 50 pages ≈ cents. Re-embedding on update = same. GraphRAG rebuild = heavier. Agentic = higher token loops.
