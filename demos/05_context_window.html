Tap a chunk to add it (or drag it in). When the window has context, the LLM answers.

Why not all 50 pages? Token limit + cheaper + less hallucination. Context is precious.

Search vs Context — what’s the difference?

Search (previous step) decides WHICH slices win — it ranks every slice and picks the Top-K.

Context (this step) decides HOW they’re handed over — the winners are assembled inside the LLM’s reading window, trimmed to fit the token limit.

One line: Search picks the pages; Context puts them on the lawyer’s desk.
