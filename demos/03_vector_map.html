    How it scores — inside the umbrella

    • Closer to 1.00 = same meaning = higher rank. 0.00 = unrelated. That’s the whole rule the map follows.
    • mockEmbed(word) → deterministic 8-D vector (each topic sits on its own axis; related words sit at nearby angles). cosine(a,b) = dot(a,b) for normalized vectors.
    • Visual Map tab: see coordinates, clusters and distance lines.
    • How it scores tab: see the numeric cosine and the ranking it produces.
    • Real TF Projector uses 300-D Word2Vec; we use 8-D so it loads instantly on your phone. Swap to Transformers.js all-MiniLM-L6-v2 later if you want real model scores.
