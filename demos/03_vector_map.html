    For Builders — how mock works

    No API. mockEmbed(word) → 8-D normalized vector (synonym map for demo words, hash→sin for others). Cosine = dot. Real TF projector uses 300-D Word2Vec; we use 8-D for instant phone. Swap to Transformers.js later if you want.
