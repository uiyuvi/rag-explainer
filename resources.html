See real embeddings (the map you played with, at full scale)

TensorFlow Projector — real enwiki word vectors

The exact config linked here loads 300-dimension Word2Vec vectors trained on English Wikipedia. Search “hospital” and the nearest neighbours are “clinic”, “medical” — the same clustering as our demo, but with real trained numbers. Desktop-first.

Embedding Atlas (Apple)

A newer browser tool for exploring embedding spaces in 2-D/3-D. Lighter than the Projector and touch-friendly — closest mobile-friendly alternative to our Closest-Match Map.

How the fingerprints are really made

all-MiniLM-L6-v2 — the open model behind “768-D” claims

Model card for a widely used open embedding model. Turns any sentence into a fixed-length vector — what our mockEmbed imitates with 8 dimensions.

Sentence-Transformers docs — cosine similarity explained

The documentation for the library behind most text embeddings, including how cosine similarity compares two vectors — the scoring you saw in Search.

Where fingerprints are stored and searched

Pinecone — what a vector database actually is

A clear explainer on why fingerprints need a specialised store instead of a normal database, and how nearest-neighbour search scales to millions of vectors.

The full pattern, and where it goes next

LangChain — RAG concepts

The retrieve-augment-generate pattern used in our pipeline simulator, described end-to-end: loaders, chunking, embeddings, retrieval, and grounded answers.

Microsoft GraphRAG

Graph-based retrieval — builds an entity graph on top of your documents so questions like “how are X and Y connected?” get answered. The heavier sibling of Basic RAG.

Anthropic — building effective agents

How agent loops work — search, check, search again — the idea behind Agentic RAG, where the model decides the next step instead of one fixed pipeline.

Use Cases — Generic

Customer Support • Healthcare • Finance/Insurance • Legal • Education • Enterprise Search — same pattern: private docs + question → grounded answer + citations. All need re-processing on update (Basic cheapest).
